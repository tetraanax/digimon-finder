# 나의 파트너 디지몬 (digimon-finder)

성별·키·몸무게·나이·혈액형을 입력하면, 디지털 네트워크를 추적하는 연출 끝에 나와 맞는 성장기 파트너 디지몬을 보여 주는 팬메이드 심리테스트예요.

빌드 도구 없이 HTML·CSS·JS 파일만으로 돌아가요.

## 폴더 구조

```
index.html       화면 구조
css/style.css    디자인 (우주 테마 한 가지)
js/data.js       파트너 후보와 정통 진화 루트 ← 후보 수정은 여기서
js/journey-data.js 여행 규칙: 진화 시점, 체급(용량), 성향, 분기 진화, 행동 선택지, 구역별 사건
js/evolution.js  진화 연출 (화면 전체 애니메이션)
js/digi-info.js  진화형 디지몬 설명 (진화 연출 끝과 정보 팝오버에 나와요)
js/network.js    디지털 네트워크 장면 (노드 트리, 구역, 오로라 배경) — 재사용 가능한 모듈
js/app.js        궁합 계산, 결과 카드, 여행 모드
digimon.json     디지몬 도감 (국문명 · 그림 파일 이름 · 상세 페이지 주소 · 등급 · 유형 · 속성 · 필살기 · 관련 디지몬)
js/digimon-db.js digimon.json 에서 만든 앱용 표 (자동 생성)
img/digimon/     디지몬 이미지 (digimon.json 의 image 와 같은 이름)
tools/build-db.js        digimon.json → js/digimon-db.js 다시 만들기
tools/scrape-details.js  도감 상세 페이지에서 등급 · 유형 · 속성 · 필살기 · 관련 디지몬 모으기
tools/scrape-evolutions.js  Wikimon 에서 근거 있는 진화 관계(진화 후 목록) 모으기
server.js        로컬 개발용 서버 (배포에는 필요 없음)
```

## 실행하기

`index.html`을 더블클릭해도 열려요. 로컬 서버로 띄우려면 (Node.js 필요, 설치할 패키지 없음):

```bash
npm start
```

그다음 브라우저에서 http://localhost:5173 을 열어요.

## 후보 추가·수정

`js/data.js`의 `window.DIGI` 목록에 한 줄씩 추가하면 돼요.

```js
{ko:'아구몬', en:'Agumon', attr:'vac', type:'파충류형', size:2, vibe:['brave','wild'], line:['그레이몬','메탈그레이몬','워그레이몬'], img:'', d:'한 줄 소개'},
```

- `attr`: `vac` 백신 · `dat` 데이터 · `vir` 바이러스 · `fre` 프리
- `size`: 1 작고 날렵 · 2 보통 · 3 크고 듬직 (키·몸무게의 BMI와 비교해요)
- `vibe`: `brave` · `calm` · `clever` · `gentle` · `wild` 중 2개 (나이·혈액형과 비교해요)
- `line`: 성숙기·완전체·궁극체 정통 진화. Wikimon 진화 관계에 있을 때만 쓰여요. 모르면 `'?'` (그 단계는 Wikimon에서 굵게 표시된 대표 진화를 정통 진화로 써요)
- `img`: 이미지 경로(예: `img/agumon.png`). 비워 두면 속성 색의 도트 알 그림이 나와요.

### 이미지와 도감 정보

- 그림과 도감 정보는 `digimon.json`을 따라요. 디지몬마다 공식 한국어 이름, 그림 파일 이름(`img/digimon/`), 상세 페이지 주소가 있고, 상세 페이지에서 모은 등급 · 유형 · 속성 · 필살기 · 관련된 디지몬이 들어 있어요.
- 앱 데이터의 이름이 도감과 조금 다르면 맞춰서 찾아요 (`js/images.js`): `벨페몬 - 슬립 모드` → `벨페몬: 슬립 모드`, 끝이 X인 이름 → `(X항체)`, 그리고 `ALIAS` 표 (누메몬 → 워매몬, 나노몬 → 데이터몬, 드리모게몬 → 두리몬, 켄타루몬 → 켄터스몬, 메탈그레이몬 → 메탈그레이몬(백신종) 등).
- X항체 그림이 없으면 기본 모습 그림을, 도감에 없는 디지몬은 속성 색 디지알 그림을 보여 줘요.
- 여행 패널의 디지몬 정보 팝오버에 도감 등급 · 유형 · 필살기 · 관련된 디지몬이 나와요. 속성을 따로 정하지 않은 디지몬은 도감 속성을 써요. 설명 문장은 공식 프로필을 옮기지 않고 `js/digi-info.js`에 직접 쓴 문장을 써요.
- `digimon.json`이나 `img/digimon/`을 바꾸면 한 번 실행하세요: `node tools/build-db.js`
- 상세 정보를 다시 모으려면: `node tools/scrape-details.js` (이미 받은 디지몬은 건너뛰어요. 전부 다시 받기는 `--force`)
- 진화 관계를 다시 모으려면: `node tools/scrape-evolutions.js` 다음 `node tools/build-db.js`. [Wikimon](https://wikimon.net)의 디지몬 문서마다 있는 "Evolves To(진화 후)" 목록에서 **근거 작품(애니 · 게임 · 카드 · V펫)이 달린 줄만** 가져와 `digimon.json`의 `evolvesTo`(`{ id, main, src }`)에 넣어요. Wikimon 문서에 적힌 도감 id(digimon.net 주소)로 짝지어서 이름을 짐작하지 않아요. "Lv.4 디지몬 아무나" 같은 넓은 카드 규칙은 버려요. 받은 원본은 `tools/wikimon-raw.json`에 남기고(깃에는 올리지 않아요), 다시 실행하면 원본을 재사용해요 (새로 받기는 `--force`). 지금 1325마리 중 1302마리가 연결돼 있고 진화 관계는 약 1만 5천 개예요.

## 궁합 계산 방식

1. **혈액형:** 어울리는 속성을 정해요. A형은 데이터, B형은 프리·바이러스, O형은 백신, AB형은 바이러스·데이터와 잘 맞아요.
2. **키와 몸무게:** BMI로 작은 파트너, 보통 파트너, 큰 파트너 중 어느 쪽이 맞는지 정해요.
3. **나이:** 어울리는 성향을 정해요.
4. **성별:** 판정에는 쓰지 않고, 운을 정하는 씨앗값에만 들어가요.
5. **랜덤성:** 점수에 입력값으로 정해지는 운을 곱해서 1등을 뽑아요. 같은 입력이면 항상 같은 결과가 나오고, "운명 다시 굴리기"를 누르면 다른 결과가 나와요.

## 여행 모드

결과 카드에서 **파트너와 여행 떠나기**를 누르면 노드 트리 위에 구역 이름이 나타나요. 처음부터 여행의 끝까지 약 30분이 걸려요.

1. **구역 고르기:** 구역 이름이나 노드 덩어리를 눌러요. **마우스 휠**(모바일은 두 손가락)로 확대·축소하고, 화면을 **끌어서**(모바일은 한 손가락) 돌릴 수 있어요. 오른쪽 아래 버튼(⟲ ▲ ⟳ ▼)을 누르고 있으면 계속 돌아가고, ⌂는 시점을 처음으로 돌려요.
   - **1인칭(시점 고정):** 오른쪽 아래 **1인칭** 버튼을 켜 두면, 구역과 구역 사이를 이동할 때 카메라가 나를 뜻하는 빛나는 점 바로 뒤, 조금 위에서 이동 방향을 바라보며 따라가요. 점은 화면 아래쪽에 보이고 그 너머로 가는 길이 펼쳐져요. 화면 가장자리에 빛이 돌고, 도착하면 원래 시점으로 돌아와요. 카메라 뒤로 이어지는 선도 화면 앞에서 잘라 그려서, 지나온 점과 이어진 선이 사라지지 않아요. 구역 안을 돌아다닐 때는 평소 시점이에요. 켜고 끈 상태는 이 브라우저에 기억돼요. 거리와 각도는 `js/network.js`의 `FPV_DIST`, `FPV_TILT`로 바꿀 수 있어요.
2. **이동:** 노드를 한 칸씩 딛으며 이동하고, 구역 사이를 잇는 직선 연결(릴레이)은 멈추지 않고 쭉 지나가요. 먼 구역일수록 오래 걸리고, 왼쪽 아래에 도착까지 남은 시간이 "17000ms"처럼 ms 단위로 줄어들어요.
3. **구역 탐험:** 도착하면 그 구역이 화면을 가득 채우도록 확대되고, 구역 안의 노드를 6~8걸음 돌아다녀요.
   - 걸음마다 무언가 일어나요. 대부분은 저절로 일어나는 일이고, 직접 고르는 건 갈림길에서만이에요 (아래 "사건과 선택").
   - 일어난 일은 화면 중앙 하단에 크게 뜨고, 지난 기록은 오른쪽 패널에서 볼 수 있어요.
4. **디지몬 정보:** 오른쪽 패널 위쪽의 디지몬 이름(또는 그림)을 누르면 큰 그림, 단계, 용량, 설명, 진화 경로, 다녀간 구역이 팝오버로 나와요. 루트 카드를 누르면 지나온 모습의 정보를 볼 수 있어요. 바깥을 누르거나 Esc로 닫아요. 진화형 설명은 `js/digi-info.js`, 성장기 파트너 설명은 `js/data.js`의 `d`에 있어요.
5. 탐험이 끝나면 다음 구역을 골라요. 패널의 **빠르게 ▶▶**를 누르면 3배 속도로 진행돼요.

### 사건과 선택

삶을 한 해씩 살아가는 인생 시뮬레이션처럼, 대부분은 저절로 흘러가고 가끔 갈림길에서만 직접 골라요. 숫자는 모두 `js/journey-data.js`에 있어요.

- **훈련 방침:** 오른쪽 패널에서 자유롭게 · 모험 · 교류 · 탐구 · 수련 · 그림자 · 휴식 중 하나를 골라 두면, 걸음마다 그 성향이 저절로 자라요. 휴식은 성장 대신 컨디션을 회복해요. 방침은 언제든 바꿀 수 있고 이 브라우저에 기억돼요 (`focus`).
- **선택 횟수:** 구역에 도착한 첫 걸음에는 40%, 그 뒤 걸음에는 9% 확률로 행동 선택지가 나와요. 한 구역에서 보통 0~2번이에요 (`pace`). 그 밖에는 갈림길 사건에서만 골라요.
- **저절로 일어나는 일:** 걸음마다 아래 순서로 하나를 정해요 (`rates`).
  1. **되돌아오는 일:** 예전 선택이 6~18걸음 뒤에 돌아와요. 도와준 디지몬이 은혜를 갚거나, 흡수한 데이터가 몸속에서 날뛰거나, 놓아준 라이벌이 재대결을 청해요 (`chains`).
  2. **세계 사건:** 네트워크 전체에 몇십 걸음 동안 이어지는 변화가 생겨요 (예: 대규모 패킷 폭풍, 백신 대청소). 그동안 위험이나 행운 확률, 컨디션 회복량이 달라지고, 패널에 이름이 떠요 (`worlds`).
  3. **아주 드문 일 (✧):** 오래된 디지바이스가 반응하거나, 노랫소리에 모든 상처가 아무는 일이에요 (`rares`).
  4. 조그레스 짝이 찾아오는 일, 캡슐 갈림길이에요.
  5. **위험:** 버그 떼, 삭제 프로그램, 오염된 물 등으로 컨디션이 깎여요. 어두운 네트워크에서는 1.5배 자주 일어나요. 일부는 맞서 싸울지 도망칠지 고르는 갈림길이에요 (`dangers`).
  6. **친구:** 만났던 디지몬이 놀러 오거나 도움을 청해요 (`bondVisits`, 갈림길 `trouble`).
  7. **행운:** 데이터 샘, 레어 조각, 지름길 같은 좋은 일이에요 (`lucks`).
  8. 컨디션이 낮으면 쉬어 가는 일, 그 구역에서만 일어나는 일, 평범한 일상이에요.
- **상대의 단계:** 사건에 나오는 디지몬은 장면에 맞는 단계에서 골라요. 파트너가 쫓겨 도망치거나 물리는 장면(`foe: 'strong'`)의 상대는 파트너와 같거나 높은 단계, 몰아내거나 흡수하는 장면(`foe: 'weak'`)의 상대는 파트너보다 낮은 단계예요. 그 구역에 알맞은 디지몬이 없으면 도감에서 같은 단계 디지몬을 데려와요 (`monFor`). 그래서 궁극체가 성장기에게 쫓기는 일은 없어요.
- **컨디션:** 0~100이에요. 위험한 일과 거친 선택이 깎고, 걸음마다 조금씩, 행운과 휴식이 많이 회복해요. 30 아래로 떨어지면 성장이 절반으로 줄고, 40 아래면 진화하지 않아요. 진화하면 30 회복해요 (`cond`).
- **자동 선택:** 패널의 **자동 선택**을 켜면 선택지가 나올 때 훈련 방침에 가장 맞는 걸 미리 표시하고, 9초 막대가 다 줄면 그걸로 골라요. 그 전에 직접 눌러도 돼요. 켜고 끈 상태는 기억돼요.
- **여정 지도:** 여행 기록 카드에 한 걸음을 한 칸으로 한 격자가 나와요. 칸 색으로 그 걸음에 일어난 일(선택 · 일상 · 위험 · 행운 · 드문 일 · 친구 · 세계 · 되돌아온 일 · 휴식 · 진화)을 한눈에 볼 수 있어요.

### 구역 (40개)

- **대륙·대양 (안쪽 고리):** 태평양, 아메리카, 대서양, 유럽, 아프리카, 인도양, 아시아, 오세아니아 네트워크
- **중심:** 커널
- **바깥 고리:** 딥웹 네트워크, 다크 에리어, 디지털 해저드, 어나니머스 네트워크, 파일 섬, 서버 대륙, 방화벽 요새, 버그 정크야드, 캐시 사막, 프록시 미궁, 아카이브 도서관, 바이러스 늪, 백신 성역, 쿼리 협곡, 블록체인 산맥, 클라우드 하늘섬, 양자 네트워크, 위성 궤도망, 레거시 서버 묘지, 피싱 해역, 다크웹 마켓, 미러 서버, 노이즈 폭풍지대, 코드 정글
- **숨겨진 구역 (7개):** 태양계 네트워크, 이그드라실 코어, 어비스, 사성수 결계, 올림포스 서버, 천사의 계단, X 프로그램 격리구역

구역끼리는 서로 충분히 떨어져 있어서(가장 가까운 두 구역도 약 3,800 단위) 누르기 쉬워요.

구역마다 생김새가 모두 달라요. 공용 모양을 섞어 쓰지 않고, 구역 이름에 맞춰 하나뿐인 구조를 따로 만들었어요 (`SIG` in `js/network.js`). 위아래 방향은 그대로 두고 옆으로만 돌려 놓아서 건물이나 지형은 똑바로 서 있어요.

구조의 선마다 반짝이는 작은 구슬 노드가 꿰어져 있고, 구역 둘레로 가는 반짝이 실이 흩날려요. 구역 사이는 허브끼리 잇는 연결 말고도, 가까운 구역끼리 구조 속 여러 점에서 여러 점으로 휘감기며 이어지는 덩굴 가닥(가까운 이웃은 3~5가닥)이 있어요. 나란한 가닥은 가끔 가로로 이어져 그물처럼 보이고, 가닥에서 잔가지가 돋아나요. 구슬과 덩굴은 이동할 때 멈추지 않고 지나가요. 숨겨진 구역은 일반 구역보다 훨씬 화려해요: 구슬이 더 많고 크고 여러 색으로 빠르게 반짝이며, 구역을 감싸는 기울어진 구슬 고리 3~4개와 넓게 퍼진 반짝이 껍질이 있고, 가까이 가면 노드마다 빛이 번져요. 전체 노드는 약 8만 개예요. 멀리 작게 보이는 점은 픽셀 버퍼에 한꺼번에 찍어서 노드가 많아도 부드럽게 움직여요.

- **대륙·대양:** 태평양은 말려 들어가는 거대한 파도와 물보라, 아메리카는 현수교와 강 건너 마천루, 대서양은 바다 밑 해저 케이블 다발과 중계기, 유럽은 톱니 성벽과 원뿔 지붕 탑, 아프리카는 굽이치는 강과 강가에 흩어진 무리와 아카시아, 인도양은 산호 부채와 뇌산호, 아시아는 처마 끝이 들린 층탑들, 오세아니아는 흩뿌려진 크고 작은 섬과 뱃길이에요.
- **중심과 특별 구역:** 커널은 겹겹이 싸인 기하 껍질, 딥웹은 끝없이 내려가는 나선 계단, 다크 에리어는 제멋대로 뻗은 혼돈의 점과 선, 디지털 해저드는 세 날개 경고 표식과 경고 삼각형, 어나니머스는 가운데를 바라보는 얼굴 없는 가면들이에요.
- **바깥 구역:** 파일 섬(분화구 화산섬과 야자수), 서버 대륙(줄지은 서버 랙), 방화벽 요새(휘어진 벽돌 벽과 불꽃), 버그 정크야드(뾰족한 고철 산과 묻힌 상자), 캐시 사막(초승달 모래언덕), 프록시 미궁(입구에서 출구까지 길이 이어진 진짜 미로), 아카이브 도서관(둥근 서가와 돔), 바이러스 늪(피어오르는 거품), 백신 성역(별 문양과 빛기둥), 쿼리 협곡(층진 절벽과 줄다리), 블록체인 산맥(이어진 블록 산등성이), 클라우드 하늘섬(거꾸로 된 원뿔 섬과 폭포), 양자 네트워크(세 축의 확률 구름과 얽힌 입자쌍), 위성 궤도망(행성과 점선 궤도의 위성), 레거시 서버 묘지(비석 · 울타리 · 앙상한 나무), 피싱 해역(처진 그물과 낚싯바늘), 다크웹 마켓(어지러운 천막과 등불 줄), 미러 서버(거울면 양쪽의 똑같은 두 조각), 노이즈 폭풍지대(회오리와 잔해, 번개), 코드 정글(늘어진 덩굴과 고사리)이에요.
- **숨겨진 구역:** 태양계(행성 궤도), 이그드라실 코어(세계수), 어비스(중력 우물), 사성수 결계(네 기둥 결계와 네 방위 문양), 올림포스 서버(열주와 박공 지붕의 신전), 천사의 계단(하늘로 오르는 계단과 날개, 광륜), X 프로그램 격리구역(철창 상자에 갇힌 거대한 X)이에요.

### 진화

- **일반 진화:** 능력치가 조건에 닿아야 진화해요. 걸음 수만 채워서는 진화하지 않아요. 성숙기는 가장 높은 능력치 100·합계 300, 완전체는 280·900, 궁극체는 520·1800이 필요해요. 너무 이르지 않도록 최소 걸음 수(12, 40, 80)도 있어요. 오른쪽 패널에 다음 진화까지의 진행이 보여요 (`evolveNeed`). 한 가지 능력치를 꾸준히 키우면 더 빨리 진화해요 (시험해 보니 평균 16·52·106걸음, 고르게 고르면 19·64·128걸음).
  - 성향(용기·우정·지혜·힘·어둠)은 0~999 사이 점수예요. 선택지는 한 번에 십몇~삼십몇 점, 돌아다니다 생긴 일은 몇 점씩 올려요 (`statMax`, `statGain`).
  - **근거 있는 진화만:** 다음 모습은 언제나 지금 모습의 Wikimon "진화 후" 목록(근거 작품이 있는 것)에서 바로 다음 단계인 디지몬 중에서 골라요. 아머체 · 하이브리드체 · X항체 모습은 따로 다루니 빼요. 목록에 다음 단계가 없으면 진화하지 않고 패널에 "알려진 다음 진화가 없어요"가 나와요.
  - 가장 높은 성향이 파트너 본래 성격과 맞으면 정통 루트(`line`, 없으면 대표 진화)로 진화해요.
  - 어둠이 가장 높거나 성향이 크게 기울면 그 목록 안에서 성향에 어울리는 디지몬으로 갈라져요. 어울림은 `branches` 표에 있으면 그 성향, 아니면 도감의 유형(용·공룡 → 용기, 천사·식물·새 → 우정, 기계·마법·곤충 → 지혜, 짐승·수인 → 힘)과 속성으로 정해요.
  - **진화 근거:** 디지몬 정보 팝오버의 "진화 근거"에 그 진화의 근거 작품이 최대 3개 보여요 (예: Vital Bracelet Digital Monster · 카드 Da-450).
  - **속성:** 진화형마다 백신·데이터·바이러스·프리 속성이 있어요 (`js/digi-info.js`의 `DIGI_ATTR`).
    - **어둠**이 가장 높거나 능력치 합계의 30% 이상이면 **바이러스종**으로 진화해요. 정통 루트가 바이러스종이 아니면 진화 후 목록의 바이러스종으로 가요 (없으면 일반 규칙대로).
    - 어둠이 합계의 15%도 안 되면 바이러스종 후보는 빠져요.
    - 그 밖에는 용기+우정이 앞서면 백신종, 지혜+힘이 앞서면 데이터종을 먼저 골라요. 프리종은 어느 쪽이든 후보에 들어가요.
    - 길몬·베타몬처럼 본래 바이러스종인 파트너는 정통 루트가 바이러스여도 그대로 진화해요.
  - **다음 진화 예상:** 오른쪽 패널에 지금 능력치로 진화할 후보가 검은 실루엣과 속성으로만 보이고 (이름은 ??? 로 숨겨서 진화할 때까지 누군지 몰라요), 능력치가 바뀌면 바로 바뀌어요. 후보가 여러 개면 모두 보여 주고 "N개 중 하나"라고 알려 줘요. 진화할 때 그중 하나가 무작위로 나와요.
- **캡슐진화:** 성장기·성숙기일 때 가끔 선택지에 디지멘탈 캡슐이 나와요. 고르면 아머체로 진화해요 (예: 브이몬 + 용기의 디지멘탈 → 화염드라몬). 지금 모습이 그 아머체로 진화한다는 근거가 있는 디지멘탈만 나와요 (예: 파피몬은 우정 · 희망 · 빛). 근거 있는 아머체가 하나도 없는 파트너에게는 캡슐이 나오지 않아요. 여행마다 한 번이에요 (`digimentals`).
- **진화 연출:** 진화할 때마다 화면 전체에 약 15초짜리 "데이터 증폭" 연출이 나와요 (`js/evolution.js`). 배경에는 처음부터 끝까지 16진수 데이터 열과 네트워크 성좌(노드 · 라우팅 선 · 그 위를 달리는 패킷)가 깔려요. ① 화면이 한 번 흔들리고 데이터 줄기가 가로지른 뒤 ② 원근 격자 바닥 위에서 스캔선이 몸을 훑으며 데이터로 읽어 들여요 → ③ 그림의 실제 픽셀이 아래에서부터 떨어져 나와 데이터 입자가 되고 소용돌이 구체로 모여요 → ④ **증폭:** 점점 빨라지는 박자마다 입자가 ×2 ×4 ×8 …로 복제되며 구체가 화면을 가득 채울 만큼 커지고, 주변 노드가 모두 가운데로 패킷을 보내며, 회전하는 육각 프레임과 육각 파동이 퍼져요. 왼쪽 위 판독기의 용량 숫자는 이전 모습의 용량에서 새 모습의 용량까지 치솟아요 → ⑤ **한계돌파:** 모든 데이터가 한 점으로 빨려 들어갔다가 대폭발해요 (검은 프레임 · 새 모습의 실루엣 · 하얀 섬광 · 원형과 육각 충격파) → ⑥ 흩어진 입자가 새 모습의 픽셀 자리로 날아와 몸을 짜 맞추고 실제 모습이 드러나요 → ⑦ **결과 화면:** 회전하는 디스크 플랫폼과 빛기둥 위에 새 모습이 서고, 위에 LIMIT BREAK, 가운데에 색 번짐이 가라앉으며 열리는 큰 이름, 아래에 단계 · 속성과 용량 막대(이전 → 새 용량, 증폭 배율), 그리고 모서리 괄호가 있는 패널에 설명이 한 글자씩 써져요. 조그레스는 두 디지몬이 함께 분해되어 하나로 합쳐지고, 진화 종류마다 빛 색이 달라요 (일반 하늘색, 조그레스 분홍, 캡슐 노랑, 숨겨진 구역 보라). **단계가 오를수록 화려해져요:** 성숙기는 ×8까지 차분하게, 완전체는 ×16, 궁극체는 ×64에 구체에서 번개가 튀고 결과 화면 뒤로 빛살이 돌아요. 특별 진화(숨겨진 구역)는 ×256까지 복제되고, 두 번째 폭발과 무지개 충격파, 결과 화면을 도는 별가루가 더해져요. 입자 수 · 흔들림 · 폭발 파편과 파동 수도 단계마다 커지고, 결과 화면 제목 아래 별(★☆☆☆ ~ ★★★★)로 단계가 표시돼요. 화면을 누르거나 건너뛰기·Esc를 누르면 결과 화면으로, 한 번 더 누르면 닫혀요. "동작 줄이기" 설정에서는 3배 빨라요. 빠르게 모드여도 진화 연출은 보통 속도로 나와요.
- **진화 형태별 연출:** 진화하는 모습의 종류와 속성에 따라 연출이 달라져요. 캡슐 · 조그레스가 먼저, 그다음 숨겨진 구역(칠대마왕 → 바이러스 연출, 로열나이츠 · 사성수 · 올림포스 12신 → 성스러운 연출), 그 밖에는 새 모습의 속성으로 정해요.
  - **백신종 — 성스러운 힘:** 위에서 금빛 빛기둥이 내려오고 빛의 깃털이 흩날려요. 육각 프레임 대신 16진수 글자 고리가 도는 성스러운 문양 원이 생기고, 폭발 뒤 입자가 하늘로 흩어졌다가 위에서 내려와 몸을 짜 맞춰요. 결과 화면에는 등 뒤에 문양 원, 머리 위에 광륜이 떠요 (HOLY ASCENSION).
  - **바이러스종 — 침식 · 흡수:** 화면 가장자리에서 검은 촉수가 자라 들어오고, 스캔 대신 오염 블록이 몸을 갉아먹어요. 주변 네트워크 노드가 하나씩 붉게 감염되고, 가운데에 생긴 검은 핵이 데이터를 계속 빨아들여요. 판독기에 CORRUPTION 경고가 깜빡이고 화면이 가로로 찢겨요. 폭발은 붉은 섬광이에요 (SYSTEM CORRUPTED).
  - **캡슐(아머) 진화 — 캡슐 조각:** 증폭 중에는 금빛 육각 판이 구체 둘레를 돌고, 폭발 뒤에는 금빛 껍질 조각이 사방에서 날아와 하나씩 맞물리며 캡슐을 이뤄요. 다 맞물리면 캡슐이 달아오르다가 깨져 흩어지며 새 모습이 드러나요 (CAPSULE UNLOCKED).
  - **조그레스 — DNA 결합:** 두 디지몬의 데이터가 분홍과 하늘색 두 가닥의 이중 나선으로 꼬이다가 증폭 중반부터 하나의 구체로 합쳐져요. 분홍 · 하늘색 육각 프레임이 서로 반대로 돌아요 (DNA SYNCHRONIZED).
  - **프리종:** 입자가 무지갯빛으로 빛나요 (FREE FORM). **데이터종**과 그 밖의 진화는 기본 데이터 증폭 연출이에요 (LIMIT BREAK).
- **조그레스 진화:** 지금 모습에 조그레스 짝이 있으면(예: 엑스브이몬 + 스팅몬 → 파일드라몬, 워그레이몬 + 메탈가루몬 → 오메가몬) 짝이 가끔 저절로 찾아와 친밀도가 올라요. 함께 시간을 보내 **친밀도가 80 이상**이 되면 조그레스 갈림길이 나오고(미루면 몇 걸음 뒤에 다시), 고르면 둘이 합쳐져요. 실제 조합만 넣었어요 (`jogress`).
- **친밀도:** 여행 중 만난 디지몬마다 친밀도(0~100)가 쌓여요. 선택지에 나온 디지몬은 만나기만 해도 조금 오르고, 도와주거나 구해 주면 크게 오르며, 몰아내거나 흡수하면 내려가요. 돌아다니다 마주친 디지몬도 조금씩 올라요. 선택지와 기록에 "♥ 이름 +N" 칩으로 보이고, 단계(낯선 사이 → 아는 사이 20 → 친구 45 → 단짝 80 → 영혼의 짝 100)가 오르면 기록에 남아요. 오른쪽 패널에는 지금 모습의 조그레스 짝(못 만났으면 실루엣과 ???)이 맨 위에, 그다음 친한 순서로 3명까지 하트 막대와 함께 보여요. 짝의 막대에는 조그레스에 필요한 80 눈금이 있고, 넘으면 "조그레스 가능!"으로 바뀌어요. 여행 기록에는 가장 친한 친구가 나와요. 숫자는 `js/journey-data.js`의 `bond`에서 바꿀 수 있어요.
- **숨겨진 구역:** 화면에는 조건을 알려 주지 않아요. 조건을 채우면 "낯선 신호가 잡혔어요"라는 기록과 함께 지도에 ✦ 이름이 나타나고, 그 구역을 눌러 들어가면 특별 진화해요.
  - 태양계 네트워크는 초궁극체, 이그드라실 코어는 로열나이츠, 어비스는 칠대마왕, 사성수 결계는 사성수, 올림포스 서버는 올림포스 12신, 천사의 계단은 삼대천사, X 프로그램 격리구역은 X항체가 돼요. 무리 중 지금 모습에서 진화한다는 근거가 있는 디지몬이 있으면 그쪽을 먼저 골라요 (예: 안티라몬 → 사성수 중 근거 있는 쪽). 근거가 없으면 숨겨진 구역의 특별한 힘으로 진화하는 게임 설정이에요.
  - **타락:** 오파니몬(또는 오파니몬X)이 어비스에 들어가면 칠대마왕 대신 **오파니몬 - 폴다운 모드**(X항체면 그 X항체 모습)로 타락해요. 천사의 계단에서 이미 오파니몬이 되었어도 한 번 더 진화해요. 연출은 바이러스종처럼 어둠이 몸을 갉아먹는 모습이에요 (`secrets`의 `fall`).
  - **X항체:** 이미 다른 특별 진화를 한 모습(예: 리리스몬)도 X 프로그램 격리구역에 들어가면 그 X항체 모습(리리스몬X)으로 한 번 더 진화해요. 도감에 그 X항체 모습이 있을 때만 일어나요.
  - 구역 방문이 아니라 성향 점수가 기준에 닿으면 열려요 (예: 어둠이 아주 높으면 어비스). 조건은 `js/journey-data.js`의 `secrets`에 있어요.
  - 화면에는 숨겨진 구역이 몇 개인지도 나오지 않고, 열린 구역 이름만 패널에 남아요.
- **체급(용량):** 단계마다 용량이 정해져 있어요 (예: 성장기 21MB, 성숙기 2.1GB, 초궁극체 33TB). 이름으로 계산하므로 같은 디지몬은 늘 같은 용량이에요 (`capacity`). 다시 진화했는데 정해진 용량이 지금보다 작으면(예: 초궁극체 → 타락이나 X항체) 지금 용량의 1.3~2배로 늘어나서, 진화할 때 용량이 줄어드는 일은 없어요.

### 여행의 끝

160걸음(`journeyEnd`)에 닿으면 그 구역 탐험을 마친 뒤 여행 기록 카드가 나와요. 단계, 용량, 진화 방식, 거쳐 온 구역이 타임라인으로 보이고, "계속 여행하기"로 이어서 다닐 수도 있어요.

### 시간 조절

`js/journey-data.js`에서 바꿀 수 있어요.

- `roamSteps`: 한 구역에서 걷는 걸음 수
- `pace`: 선택지가 나올 확률과 자동 선택 대기 시간
- `rates`: 사건 종류별로 일어날 확률
- `roamPause`: 걸음 사이 쉬는 시간
- `evolveNeed`, `journeyEnd`: 진화 조건과 여행의 끝 시점

### 네트워크 모듈 재사용

```js
const net = new DigiNetwork(canvas, { seed: 1999, clusters: 44, onStatus: (eyebrow, title) => {} });
net.open();                                  // 렌더링 시작
await net.trace({ partner: '아구몬', names }); // 신호 추적 연출
net.setExplore(true);                        // 구역 이름 표시
await net.travelTo(regionId, { label, sub, flash }); // 먼 곳일수록 오래 걸려요
await net.wander(regionId);                  // 같은 구역 안의 다른 노드로 한 걸음
net.setStay(true);                           // 구역 탐험 중에는 카메라를 가까이
net.unlock(8);                               // 숨겨진 구역 열기
await net.evolveFx({ label, sub, title });   // 지금 위치에서 진화 연출
net.zoomBy(1.2);                             // 확대·축소 (휠과 같은 동작)
```

- `seed`가 같으면 항상 같은 네트워크가 만들어져요.
- `clusters`로 노드 덩어리 수(밀도)를 조절할 수 있어요.

### 개발용 디버그

주소 끝에 `#debug`를 붙이면 브라우저 콘솔에서 `__digi.travel(구역번호)`로 이동을, `__digi.journey`로 현재 상태를 볼 수 있어요. `__digi.evolve({ name: '파일드라몬', stage: 2, label: '완전체', partner: '스팅몬' }, 'JOGRESS EVOLUTION')`로 진화 연출을 바로 시험할 수 있어요. 구역 번호는 0 태평양, 1 아메리카, 2 대서양, 3 유럽, 4 아프리카, 5 인도양, 6 아시아, 7 오세아니아, 8 태양계, 9 이그드라실, 10 커널, 11 딥웹, 12 다크 에리어, 13 디지털 해저드, 14 어나니머스, 15~34 그 밖의 구역, 35~39 새 숨겨진 구역이에요. `__digi.net.regionId('어비스')`처럼 이름으로 번호를 찾을 수 있어요.
